# Hextris

<img src="images/twitter-opengraph.png" width="100px"><br>

[English](README.md) | **简体中文**

一款受俄罗斯方块启发的益智游戏。在线游玩：[www.hextris.io](http://www.hextris.io) 或 [https://hextris.github.io/hextris](https://hextris.github.io/hextris)。

## 语言选项

**语言切换**功能：游戏默认以英文为主界面，点击右上角的 `EN / 中文` 按钮即可切换为**简体中文**，选择会被自动记忆。
